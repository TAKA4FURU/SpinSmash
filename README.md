# SpinSmash

ボールに回転をかけてパワーアップし、ブロックを撃ち抜くスマホ向けブロック崩し（縦画面・一人プレイ）。

## 遊び方

- タイトル画面の「スタート」で開始。ステージは番号のみ表示。全11ステージで1周し、ステージ12からは色違いの2周目（周ごとにブロックHP×2・降下速度×1.3、最大3倍）。終わりなき戦いのハイスコア勝負。1周の内容（うちゅう・くさ・みず・ほのお・でんき・ひこう・いわ・こおり・どく・はがね・せいぶつ）。
- 背景は遠・中・近の3層で、遠いほどゆっくり（×0.3）、近いほど速く（×2.5）流れます。近い層は大きくぼかして描いています。
- ブロックは上から降りてきて、画面の一番下まで流れて消えます（1ステージのブロック量は5倍）。画面内のブロックが少ないと速く降ります。ブロック（壊せないものも）がパドル中央の黄色いコックピットに触れるとクラッシュ（ミス）：ボールは全部なくなり1個から、周りのブロックが消えて2秒無敵。パドルは画面の下半分で自由に動かせます。ボスのHPはボールの数で変わる（1個＝1/3、10個＝等倍、100個＝約3倍、最大10倍）。撃破ボーナスは倒した時のボールが少ないほど高い（1個×10・2〜3個×5・4〜9個×2）。
- 特殊ブロック（ステージが進むほど増える）：大きい／小さい／鉄板（クリア条件外、ステージ3から）／バンパー（当たると加速、ステージ2から）。鉄板・バンパーはレーザーでだけ削れる（HPはボスの15倍、壊すと超高得点）／爆弾（周りを吹き飛ばす・連鎖）／分裂（壊すと4つに分かれる）／宝箱（必ずアイテム）／水晶（レーザーでしか壊せない・壊すと高得点＋宝石、ステージ2から）
- はがね・どく・でんきには壊せない鉄板の迷路（細い通路の奥に宝）。いわにはボス級の巨大岩が3個（HPはボスの1.2倍、壊すと大量スコア＋アイテム3個）。
- ステージ開始時にヒントが約3秒表示されます（タップで閉じる・まだ見ていないものを優先）。まだ説明していないアイテムは、ステージ開始前のヒントで2つずつ紹介します。
- LASER：ボールが小さく強い光のレーザーに（通常は赤、マグネット中は紫）。長い軌跡、回転なしでまっすぐ（水流・風でも曲がらない）、常に高速で最高速度相当のダメージ。ボールは32個まで（調整パネルで16〜128、多い分は消える）。次のミスまで。
- ボールの種類（武器アイテム）：NORMAL（64個）／LASER（32個）／SPINNING（らせん状に進む・32個）／BIG（3倍の大きさ・威力5倍・8個）／CONTROL（iPhoneの左右の傾きで曲がる・振ると高速スピン・64個）／FIRE・ICE・THUNDER・POISON（属性：得意なステージで1.3倍、苦手なステージで0.25倍）。取った種類は画面の一番下に並び、パドルを一番下まで降ろして触れると切り替え。切り替えると上限を超えた分は消える。ミス（またはステージが変わると）で全部なくなる。
- HELP：画面の一番下にヘルプパドル。自分のパドルと同じ横位置を動き、普通に跳ね返すだけ（ブロックや弾に当たっても平気）。WIDEで一緒に広がる。次のミスまで。
- HI-SPEED（お邪魔）：取るたびにボールが速くなる（最高速度+0.5、最大3.0）。威力は上がらない。次のミスまで。
- ボールの速さ（初期値）：初速0.1・最高速0.8・ビーム発生0.6（子どもやゲームに慣れていない人向け）。
- アイテムは形で見分けられるアイコン：コイン（銅・銀・金）、六角形のダイヤ、数字入りボール（×2〜×10）、磁石（MAG）、星（LASER）、左右矢印（WIDE）、剣（POW）、回転矢印（SPIN）、砂時計（SLOW）、盾（BARRIER）、ハート（1UP）、おばけ（透明）、警告色の早送り（HI-SPEED）、2本のパドル（HELP）。ブロックのHP表示はなし（ヒビと暗さで残りがわかる）。
- スコア用アイテム：銅コイン1,000／銀コイン5,000／金コイン20,000／ダイヤ100,000（×ステージ数×倍率）。アイテムの約半分が宝石。
- ステージクリアごとに3つのパワーアップから1つを選べます（攻撃力・アイテム運・パドル拡張・分裂・爆裂・残機+1・コンボ持続・スコアアップ・常備バリア・常備マグネット）。ゲームオーバーまで累積。
- コンボの数・10コンボごとの文字・フィーバーの説明は、背景とブロックの間に控えめに表示（ボールが見づらくならないように）。ダメージの数字はオプションで表示オン／オフ。
- 鉄板・バンパーは各区間に必ず1列の通り道を空けて配置（自機が通れる隙間を確保）。
- 残機は最大8。8の時に1UP（またはパワーアップの残機+1）を取るとスコアボーナス（50,000×ステージ数）。
- ポーズ中の「タイトルへ」（もう一度タップで確定）で、そこまでのスコアを記録して結果画面へ（ランキング送信もできる）。
- コンボ：ブロックを壊すたびに+1、4秒壊さないかミスで終了。10コンボごとにスコア倍率+0.5（最大×5）。
- 金色ブロック：各ステージ30%で1個。壊すとボール+50個と大きなボーナス（JACKPOT）。
- プレイ中はハイスコアまでの残り点数、終了時はオンラインランキングの順位相当と「あと何点」を表示します。

- 画面を左右にドラッグしてパドルを操作し、タップで発射します。
- 打つ瞬間にパドルを横へ擦ると、ボールに回転がかかります。
- 回転をかけて打つほどボールが加速し、速いほどブロックに大きなダメージを与えます。
- 一定の速度を超えると、ボールがビームをまといます。
- 一撃で倒したブロックは貫通します。最高速度なら、一番奥のブロックまで一撃で倒せます。
- 指を上下に動かすとパドルも上下に動きます。振り上げて打つと強打、振り下げながら打つと少し減速します。パドルの裏側で打つと下へ飛ぶので、自分で落とさないよう注意。
- iPhoneを振ると、周りの壁（上・左右）が約0.35秒揺れます。揺れている間に壁に当たったボールは、回転MAX・振り上げMAX扱い（最高速度まで加速し、時間とともに元の速さへ戻る）になり、向きも約20°変わります。天井とブロックの間で垂直に往復してしまった時の脱出用です（初回スタート時にモーションセンサーの許可を求めます）。

## ブロック・アイテム・ギミック

- ブロック：普通／硬い（金属枠）／★アイテム／毒（どくステージ）。左右に動く列もあります。
- アイテム：WIDE（パドル幅1.5倍）、POW（ダメージ2倍）、SPIN（最大回転＋加速）、SLOW（減速）、BARRIER（一度だけ下で跳ね返す）、1UP、×2／×3／×5／×10（ボールが増える。最後の1個が残っていればミスにならない）、MAG（次のミスまで。近くのアイテムは自動で寄ってくる。二本指で触れている間はボールを吸着・引き寄せ、離すと弾く）、透明（ハズレ：6秒間パドルが見えない）。
- ステージごとのギミック：くさ（回復）、みず（水流）、ほのお（延焼）、でんき（放電）、ひこう（横風）、いわ（防御3）、こおり（回転が減らない）、どく（毒でダメージ半減）、はがね（防御8）、せいぶつ（回復・復活）。
- 止めたパドルを当たる直前に振り始めると「PERFECT!」。5ラリーごとにスコア倍率アップ（最大×4）。
- 最高速付近を保つとフィーバー（8秒間、一撃・落ちない・スコア2倍）。

## ボス

ブロックを全部壊すと、その属性のボスが登場します（第10ステージはラスボス）。ボスは弾を撃ってきて、パドルに当たるとしばらくしびれます（動きが鈍く、幅が縮む）。HPが半分を切ると攻撃が激しくなります。

## BGM

素材ファイルを使わず、ブラウザ内で8bit風の音色（矩形波・三角波・ノイズ）を合成して演奏します。タイトル、各ステージ（10曲）、ボス、ラスボスの曲と、クリア・ゲームオーバー・オールクリアのジングル。フィーバー中はテンポが上がって伴奏が増えます。

## ランキング

ゲーム終了時に名前を入れて送信すると、Googleスプレッドシート（Apps Script）に記録されます。送信先は `index.html` の `RANKING_URL`、受け口のコードは `gas/Code.gs`。遊びに関わる設定を初期値から変えたプレイ・テスト用のステージ移動を使ったプレイは送信されず、端末内に「参考」記録として残ります（巻き戻しはOK）。

## テストモード

右上の ⚙ で調整パネルを開くと、回転・速度・ダメージ・音量・演出などを調整できます（開いている間はポーズ）。変更はすぐ反映されます。
