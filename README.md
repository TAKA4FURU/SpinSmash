# SpinSmash

ボールに回転をかけてパワーアップし、ブロックを撃ち抜くスマホ向けブロック崩し（縦画面・一人プレイ）。

## 遊び方

- タイトル画面の「スタート」で開始。全10ステージ（くさ・みず・ほのお・でんき・ひこう・いわ・こおり・どく・はがね・せいぶつ）。

- 画面を左右にドラッグしてパドルを操作し、タップで発射します。
- 打つ瞬間にパドルを横へ擦ると、ボールに回転がかかります。
- 回転をかけて打つほどボールが加速し、速いほどブロックに大きなダメージを与えます。
- 一定の速度を超えると、ボールがビームをまといます。
- 一撃で倒したブロックは貫通します。最高速度なら、一番奥のブロックまで一撃で倒せます。
- 指を上下に動かすとパドルも上下に動きます。振り上げて打つと強打、振り下げながら打つと少し減速します。パドルの裏側で打つと下へ飛ぶので、自分で落とさないよう注意。

## ブロック・アイテム・ギミック

- ブロック：普通／硬い（金属枠）／★アイテム／毒（どくステージ）。左右に動く列もあります。
- アイテム：WIDE（パドル幅1.5倍）、POW（ダメージ2倍）、SPIN（最大回転＋加速）、SLOW（減速）、BARRIER（一度だけ下で跳ね返す）、1UP。
- ステージごとのギミック：くさ（回復）、みず（水流）、ほのお（延焼）、でんき（放電）、ひこう（横風）、いわ（防御3）、こおり（回転が減らない）、どく（毒でダメージ半減）、はがね（防御8）、せいぶつ（回復・復活）。
- 止めたパドルを当たる直前に振り始めると「PERFECT!」。5ラリーごとにスコア倍率アップ（最大×4）。
- 最高速付近を保つとフィーバー（8秒間、一撃・落ちない・スコア2倍）。

## テストモード

右上の ⚙ で調整パネルを開くと、回転・速度・ダメージ・音量・演出などを調整できます（開いている間はポーズ）。変更はすぐ反映されます。
